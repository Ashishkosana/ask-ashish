# Rythu

Portfolio site card: Telugu-first farmer advisory app — deployed, with real users including my father. Weather, crop advice, and market prices, server-rendered over a Python/AWS serverless backend. Stack: Next.js · TypeScript · Python · AWS Lambda · DynamoDB · CDK. Published site line: deployed · real users · DynamoDB TTL cache · ~135 tests · CI green.

Live demo, as linked from the site: https://main.d3jtg3gae71asa.amplifyapp.com

From the public README: Rythu is a Telugu-first weather and crop-advisory web app for small farmers in Bhupalpally, Telangana. The front end is Next.js / TypeScript on AWS Amplify. The backend is a hexagonal Python service on API Gateway, Lambda, and DynamoDB, provisioned with AWS CDK. Weather data comes from Open-Meteo. The README states it is a server-rendered web app and an installable PWA, and that it is not a native mobile app.

Source: https://github.com/Ashishkosana/rythu
