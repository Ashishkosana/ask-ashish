# About this chat

This chat answers as Ashish Kosana from published materials only: the public site text and the project notes in this corpus. It cites those notes. If a fact is not in the notes, it does not guess.

It is not a private memory of conversations, and it does not index every GitHub repository. The résumé PDF on the site is linked but not ingested; education and work lines here are the live site text.

The service behind the chat is https://github.com/Ashishkosana/ask-ashish. It is a separate API. The static site does not embed an API key.
