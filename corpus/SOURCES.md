# Corpus sources

These files are hand-written placeholders. Each one is limited to wording already public on [ashishkosana.com](https://www.ashishkosana.com/) or in the linked public README. They are not a private career folder, a Gmail export, or a dump of every repository.

A later **green fact-bank export** (approved facts only) should replace these placeholders. Until that export exists, edit these files by hand and keep `sources.json` in sync. Do not add unpublished employers, dates, or metrics.

`SOURCES.md` is not indexed. `sources.json` is the machine map from file to public URL and is not indexed either.

The public résumé PDF (`https://www.ashishkosana.com/resume.pdf`) is **not** copied into this repo yet. Education and experience text below comes from the live site HTML. Dropping `resume.pdf` next to these notes (and adding it to `sources.json`) is enough for ingest to pick it up.
